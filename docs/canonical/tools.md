# Tool Contracts (ACI)

JSON Schema for every tool the agent can call. These schemas are loaded into the LLM system prompt. Tool names are the canonical identifiers used in agents.tools_enabled, messages.tool_name, and audit_log.tool_name.

## 5.1 search_products

| Field | Type | Required | Constraints |
| --- | --- | --- | --- |
| query | string | No | Free-text search. Max 200 chars. |
| category | string | No | Exact match on products.category |
| color | string | No | Exact match on product_variants.color |
| size | string | No | Exact match on product_variants.size |
| brand | string | No | Exact match on products.brand |
| price_max | number | No | Filter: price <= price_max |
| in_stock_only | boolean | No | Default: true. Filter: stock > 0 |
| limit | integer | No | Default: 5. Range: 1-20. |
Returns: Array<{ product_id, variant_id, name, description, category, brand, price, size, color, stock, image_url }>

Access: Read-only. Tenant-scoped. Uses hybrid retrieval: SQL filters → pg_trgm → optional rerank.

## 5.2 check_stock

| Field | Type | Required | Constraints |
| --- | --- | --- | --- |
| product_id | string (UUID) | Yes | Must exist in tenant’s products |
| variant_id | string (UUID) | No | If omitted, returns all variants |
Returns: { in_stock: bool, quantity: int, variants: Array<{ variant_id, size, color, stock }> }

## 5.3 add_to_cart

| Field | Type | Required | Constraints |
| --- | --- | --- | --- |
| product_id | string (UUID) | Yes | Must come from a prior search_products result in this conversation |
| variant_id | string (UUID) | No | Required if product has variants |
| quantity | integer | Yes | Range: 1-99 |
Returns: Updated cart object { items: [...], item_count, subtotal }

Side effect: Writes to conversations.cart_state ONLY. Does not touch products/stock.

## 5.4 remove_from_cart

| Field | Type | Required | Constraints |
| --- | --- | --- | --- |
| product_id | string (UUID) | Yes | Must exist in current cart |
| variant_id | string (UUID) | No | If product has variants |
Returns: Updated cart object.

## 5.5 calculate_total

| Field | Type | Required | Constraints |
| --- | --- | --- | --- |
| conversation_id | string (UUID) | Yes | Implicit from context (injected by orchestrator) |
Returns: { items: [{ name, qty, unit_price, line_total }], subtotal, delivery_fee, total }

Execution: DETERMINISTIC Python function. Reads cart_state, queries current prices, applies business rules (delivery fee logic). NO LLM INVOLVEMENT.

## 5.6 create_order

| Field | Type | Required | Constraints |
| --- | --- | --- | --- |
| conversation_id | string (UUID) | Yes | Implicit from context |
| delivery_name | string | Yes | Customer name |
| delivery_phone | string | Yes | E.164 or local format |
| delivery_address | string | Yes | Full address |
| delivery_city | string | Yes |  |
| notes | string | No | Customer notes |
| idempotency_key | string | Yes | Generated by orchestrator: conv_id + timestamp hash |
PRECONDITION: conversations.confirm_state MUST be true. If false, tool returns error and agent must ask for confirmation.

Returns: { order_id, status: 'pending', summary }

Side effects: Creates order + order_items records. Resets cart_state. Sends merchant notification.

## 5.7 get_order_status

| Field | Type | Required | Constraints |
| --- | --- | --- | --- |
| order_id | string (UUID) | Yes | Must belong to current customer |
Returns: { order_id, status, items, total, created_at, updated_at }

## 5.8 analyze_image

| Field | Type | Required | Constraints |
| --- | --- | --- | --- |
| image_url | string | Yes | URL to image in Supabase Storage |
| conversation_summary | string | Yes | Last 3 messages summarized (injected by orchestrator) |
| task | string | Yes | Enum: diagnose, identify_product, visual_search |
Returns: { analysis: string, confidence: float, tags: string[], suggested_products: UUID[] }

Execution: Calls vision model (Gemini Flash). Result is validated, then injected into chat model context.

## 5.9 escalate_to_human

| Field | Type | Required | Constraints |
| --- | --- | --- | --- |
| reason | string | Yes | Why the agent is escalating |
| conversation_id | string (UUID) | Yes | Implicit from context |
Side effects: Sets conversation.mode = 'manual'. Sends dashboard notification + optional WhatsApp message to merchant.
